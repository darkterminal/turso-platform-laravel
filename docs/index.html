Why this package

Laravel wiring, SDK power.

This package keeps HTTP and contract logic in turso-api-client-php, while giving Laravel apps the familiar config, container, and facade ergonomics.

Auto-discovered

Service provider and facade are registered through Laravel package discovery. Install, set env vars, and start calling TursoPlatform::....

Safe config boundaries

Token is read from TURSO_PLATFORM_API_TOKEN at resolution time. The package fails fast with clear configuration exceptions when required config is missing.

Facade or DI

Use TursoPlatform facade, inject Client, or resolve TursoPlatformManager. All resolve the same shared SDK client.

Coverage

Every SDK resource, Laravel-ready.

The facade maps 1:1 to the SDK client resources. Method signatures and contract behavior come from the underlying `turso-api-client-php` package.

Databases

Create, configure, token-mint, rotate, inspect usage/stats. databases().

Groups

Manage groups, locations, config, transfer, unarchive, tokens. groups().

Organizations

Read/update org settings, plans, invoices, subscription, usage. organizations().

Members & Invites

Manage users and invites with typed roles. members(), invites().

API Tokens

Personal and org-scoped Platform API token lifecycle. apiTokens().

Audit Logs

Paginated organization audit logs for operational traceability. auditLogs().

Recovery

List/restore deleted databases and groups via v3 UUID endpoints. recovery().

Auth & Locations

Validate tokens, inspect current user, list locations. auth(), user().

Install

Install, configure, call.

Add the package, set Platform API credentials, and use the facade or container binding in your Laravel app.

  1. 1

    Install package

    Require darkterminal/turso-platform-laravel in a Laravel 12+ app.

  2. 2

    Set environment

    Set TURSO_PLATFORM_API_TOKEN and optional org slug/UUID. Publish config if needed.

  3. 3

    Use facade or DI

    Call TursoPlatform::databases()->list() or inject Client. See the user manual.

shell
$ composer require darkterminal/turso-platform-laravel

# .env
$ TURSO_PLATFORM_API_TOKEN=...
$ TURSO_PLATFORM_ORGANIZATION=acme

# optional
$ php artisan vendor:publish --tag=turso-platform-config
